# 🔐 Security Policy

## Kebijakan Penggunaan

Tool ini dirancang untuk:
- Pengujian keamanan pada aset **milik sendiri**
- Bug bounty program yang **resmi**
- Kontrak pentest dengan **izin tertulis**
- Edukasi keamanan web

Tool ini TIDAK boleh digunakan untuk:
- ❌ Scan target tanpa izin (melanggar UU ITE & hukum internasional)
- ❌ Menyerang sistem pihak ketiga
- ❌ Aktivitas perusakan atau pencurian data

## Melaporkan Kerentanan pada Tool Ini

Menemukan bug di scanner?

1. JANGAN buka issue publik untuk bug keamanan
2. Gunakan **GitHub Security Advisory** (tab Security → Report a vulnerability)
3. Sertakan: versi, langkah reproduksi, dampak, dan PoC

Laporan privat ditangani dalam maksimal 72 jam.
